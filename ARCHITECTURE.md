# Architecture

The monitored business service exposes a small event catalog and registration API. Conditional `UPDATE events SET booked=booked+1 WHERE booked<capacity` acquires a database write lock, so concurrent successful registrations cannot oversell. Registration insertion happens in the same transaction. Unique idempotency keys and `(event_id,email)` constraints reject duplicates; a conflict rolls back the capacity increment. Replaying the same key and normalized body returns the original ID with 200; creation returns 201; a different body under the same key returns 409.

The middleware normalizes labels to route templates, counts outcomes and records duration using a monotonic clock. Unknown paths share `/unmatched`. IDs, emails, paths with IDs and tokens never become metric labels. Logs contain method, template, status, duration and correlation ID without request bodies, headers or personal data. Correlation IDs have a bounded allowlist; arbitrary input is replaced.

Prometheus counters/histograms are cumulative over process lifetime. The console's rolling sample buffer covers business endpoints only, capped at 100,000 samples and one hour maximum configured duration. A warning indicates truncation. Dashboard quantiles use exact nearest-rank percentiles over those samples. Prometheus histogram quantiles are bucket-interpolated estimates; they are not expected to match exactly. Historical chart points are twenty subdivisions of the current rolling window, not persisted time series. Use Prometheus/Grafana for longer history.

A background task probes the database and evaluates request impact every 500ms. Each signal is pending for one second before creating a deduplicated active incident, grouped by availability/latency. An incident stores triggering values, affected endpoint templates, timestamps, timeline and notes. Requests themselves do not need to call the operations UI to trigger detection. Incident state depends on the application database; a real database failure can prevent incident writes. Prometheus provides an independent scrape-plane alert.

The native Vite proxy forwards only to the local API. Fault lab authorization requires an explicit opt-in, APP_ENV=local, a >=24-character local token, loopback socket peer and an allowlisted or absent Origin. Tokens stay in React memory and are never persisted. Forwarded client-IP headers are ignored. Do not expose Vite, API or the fault token beyond localhost. Docker web mutation access is blocked and Compose disables faults.

One process/worker only. No multi-replica aggregation, migration framework, distributed tracing, real downstream booking service, queue, authentication gateway or orchestration cluster. SQLite is a native fallback, not a claim that PostgreSQL was exercised locally.
