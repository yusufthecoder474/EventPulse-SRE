# Synthetic fixture provenance

All PCAP and JSON files are generated by `python wireless-lab/scripts/generate_fixtures.py` using Python standard-library binary packing. No traffic was captured from a device. Fixed epoch 1700000000 and locally administered MACs are educational identifiers. Radiotap carries a minimal header, not measured RF metadata. Checksums and byte lengths are in `manifest.json`.

A/B/C/D/G have actual generated packet bytes decoded by TShark; E/F/H/I/J are explicit JSON state-machine simulations. Additional Ethernet-EAPOL and SAE-event fixtures cover evidence boundaries. EAPOL nonces, MIC and key data are zero placeholders, not a valid cryptographic transcript. SAE uses JSON direction/stage events only; no WPA3 hardware or cryptographic compatibility is demonstrated. Generated data does not model PHY behavior, RF loss, interference, full RSN negotiation, complete 802.1X or vendor controllers.

Regeneration is deterministic, but do not overwrite historical evidence reports. `scenarios/catalog.json` maps files to scenarios; fixtures are never selected from user-supplied paths.
